# Image Classifier 

This project involves designing and training an image classifier using the VGG16 architecture to accurately identify 102 different flower species from images.

---

##   Tech Stack

- Python  
- TensorFlow / Keras  
- Transfer Learning (VGG16)  
- Image Preprocessing and Augmentation  

---

##  Features

- Utilized pre-trained VGG16 model with fine-tuning for high accuracy  
- Classified 102 flower species with robust performance on real-world images  
- Applied image augmentation techniques to improve generalization
